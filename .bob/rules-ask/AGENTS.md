# Project Documentation Context (Non-Obvious Only)

- **TECH_STACK.md describes the *aspirational* architecture** — PostgreSQL, pgvector, NextAuth, faster-whisper, and IBM Granite are documented but **not yet implemented**. The actual running stack is SQLite + plain JWT (python-jose/bcrypt) + static mock data.
- **`config.py` is partially ignored** — `backend/security.py` hardcodes its own `SECRET_KEY` and token expiry rather than reading from `settings`. `config.py` is only used for `DATABASE_URL`.
- **The frontend is a hackathon pitch demo**, not a production app — all "live" data (student triage, DAG mastery scores, BeeBook notes, IRT item pool) is static TypeScript/Python fixtures designed to demonstrate the concept to judges.
- **`frontend/AGENTS.md`** is auto-generated by `next dev` (see `node_modules/next/dist/server/lib/generate-agent-files.js`) — do not edit it; it will be overwritten. The canonical guidance is in the root `AGENTS.md`.
- **`DESIGN.md` / `FRONTEND_DESIGN_SPEC.md`** contain the visual design intent (IBM Carbon + honey aesthetic). Reference these before modifying component styling.
- **No `.env` file exists** — backend reads `config.py` defaults directly. To override, create `backend/.env`.
